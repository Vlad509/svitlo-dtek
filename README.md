# svitlo-dtek

Стежить за графіком відключень ДТЕК Київські регіональні електромережі (dtek-krem.com.ua)
для однієї черги і пише в Telegram, коли графік змінився або з'явився графік на завтра.
Працює в GitHub Actions кожні 30 хвилин, сервер не потрібен.

## Файли

| Файл | Що робить |
|---|---|
| `dtek_krem.py` | клієнт сайту ДТЕК (curl_cffi з відбитком Chrome) |
| `check_schedule.py` | перевірка змін, повідомлення, `schedule.json` |
| `.github/workflows/dtek-schedule.yml` | розклад запуску |

Стан і графік зберігаються в окремій гілці `data`:

- `data/state.json` — хеші днів і стан помилок;
- `data/schedule.json` — графік твоєї черги для ESP32 (у приватному репозиторії читається з токеном).

## Налаштування

1. **Telegram-бот:** у @BotFather → `/newbot` → скопіюй токен. Напиши своєму боту будь-що,
   відкрий `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайди `"chat":{"id": ...}`.
2. **Твоя черга:** на своєму ПК виконай
   ```
   pip install curl_cffi
   python dtek_krem.py "м. Обухів" "вул. Київська" "10"
   ```
   (місто й вулиця точно як на сайті). Виведе щось на кшталт `['GPV3.1']`.
   Адресу в репозиторій не додавай: потрібна лише черга.
3. **Репозиторій** на GitHub, приватний. Завантаж усі файли, разом із текою `.github`.
   Запуск кожні 30 хв ≈ 1440 хв Actions на місяць із 2000 безкоштовних.
4. **Settings → Secrets and variables → Actions:**
   - Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
   - Variables: `DTEK_GROUP` = `GPV3.1` (твоя черга)
5. **Actions → DTEK schedule → Run workflow** — перший ручний запуск.

## Як читати результат першого запуску

- ✅ у Telegram прийшов графік → Incapsula пропускає GitHub, усе працює.
- ❌ червоний запуск і в лозі `blocked: WAF ...` → сайт блокує IP GitHub.
  Потрібен інший запуск (VPS або домашній ПК).
- ⚠️ `DTEK_GROUP не задано` → у лозі є список усіх черг, задай змінну.

## Примітки

- Розклад GitHub може запізнюватися на 5–30 хв: для графіка це некритично.
- Не частіше ніж кожні 30 хв: кожен запуск рахується як ціла хвилина, і при 15 хв
  безкоштовний ліміт приватного репозиторію закінчиться.
